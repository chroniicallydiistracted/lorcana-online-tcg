# BOOT-03 CI and artifact checks implementation plan

> For agentic workers: execute natively using the repository workflow; obtain an independent whole-scope review before finalizing. The Director has authorized implementation.

**Goal:** Make the local foundation pipeline repeatable and enforce it through a reviewed GitHub Actions definition, with attributable sanitized build artifacts.

**Architecture:** A WSL/Linux host launcher copies only public source and full Git history into a temporary checkout, generates disposable credentials, and runs the committed development image against a fresh PostgreSQL Compose project. A container pipeline performs ordered frozen installation, documentation/import/type/lint/unit/database/browser checks, security/dependency scans and artifact hashing. The same launcher is the Actions entry point; deployment remains separate.

**Tech stack:** Node24.21.0, pnpm10.33.0, Python3/PyYAML, Docker/Compose, PostgreSQL18, existing Playwright and dependency-free project helpers.

**Spec:** [BOOT-03 acceptance](../vision/initial_backlog.csv), blueprint sections4.3/15, [universal workflow](../DEVELOPMENT_WORKFLOW.md).

## Global constraints

- Preserve WSL source, the existing Compose project, private credentials and data. No database host ports or Docker socket in runners.
- Install the frozen lockfile with strict peer/build policy; keep product dependencies in owning packages.
- Enforce current documentation and append-only history using full Git ancestry, not shallow or source-only validation alone.
- Actions use verified full commit SHAs, read-only repository permission and no deployment secrets.
- UTC execution timestamps and content hashes identify observations; Windows/GPU/production acceptance stays pending.

## Review focus

1. Failure/cancellation must remove only the newly owned project and never publish a passing artifact.
2. Unknown licenses, unavailable advisory responses and malformed audit counts must fail closed.
3. Path traversal, symlinks, extra/missing files and mutated artifact bytes must fail validation.
4. Private files/known credentials must never enter copied source, logs, bundles or uploaded artifacts.
5. Full-history documentation checks must reject altered sealed evidence rather than silently accepting a source copy.
