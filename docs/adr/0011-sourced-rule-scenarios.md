## Decision and comparison

Exercise the same pinned runtime/configuration as the product kernel through a **test-only** Node fixture bridge. Compile it with the existing owning Vite dependency and exact vendoring aliases into a disposable directory, removed in `finally`. The bridge is neither a package export nor a release component. Production apps cannot import root development/test scripts. This avoids introducing another engine or pretending that the existing two-card product fixture can test every mechanic. The server adapter, private crypto/replay and Lab worker keep their existing ownership.

Store synthetic fixtures, commands, expected state and numbered source citations under `tests/rules/fixtures/`. These executable oracles enter the evidence fingerprint. Both official CR2.2 and scheduled CR2.3 have independent PDF/text/numbered-leaf identities; offline checks bind them to the fresh acquisition manifest, and explicit cache checks reproduce the leaf hashes. Expected outcomes are derived from official rules, not copied from observed engine output. Passing representative cases cannot certify every paragraph or card.

Keep patch originals, MIT notices, exact pin and reproducible descriptors. RULE-04 adds or expands patches for Vanish, temporary keyword loss, Adventurous, ink-drop costs and slot identity. The current closure has 346 selected files,303 runtime source/type/data files,27 unchanged upstream test files and53 patches. The superseded pre-declared chosen-event helper is no longer reachable and is removed from the selected closure. No upstream test assertion or official card definition is changed.

Vanish records actual semantic chosen operations before their primitive effect, retaining existing printed candidates. Independent slots preserve separate occurrences; previous-target references do not choose again. The actual chooser controls the Vanish predicate, separately from action ownership. Resolution waits in the bag. A private `zoneIncarnation` counter, captured by the generated effect, prevents a prior trigger affecting a source that left play and returned. Same-zone reorder does not increment it. Old synthetic indices without the field default to0. No production restore compatibility is implied; exact engine/replay identities change with these bytes.

Adventurous enters the existing simple-keyword/derived projection. It prevents challenges, including with Rush, and prevents ending a turn while a ready dry character can legally quest. Exerting it for singing/abilities can remove that obligation; drying or incompatible Reckless can make questing impossible. Existing temporary/static grant and loss paths remain, with active temporary losses removed from the derived keyword projection.

Store ink-drop counters separately in optional `G.inkDropCounters[player]`; absence means0 for older synthetic fixtures. They never become card instances, ready reusable cards or ink-card counts. Payments plan before mutation, spend only the payer's pool and consume removed drops. Ready cards are the deterministic default; root `inkDropCounters` selects a count explicitly. Nested payments own an ordered `effectInkDropCounters` queue, separate from root costs; each successful nested payment consumes its next selection. Deferred choices can supply a new bounded queue. Generated quantities use the existing dynamic-amount context. Unsafe/negative/overflow quantities fail, with command rollback. Safe integer limits are implementation bounds, not a rule limiting the physical game.
