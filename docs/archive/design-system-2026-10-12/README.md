# Original design-system draft (historical evidence)

Classification: archive. This is not the current standard.

`the-inkspire-design-system.zip` is the original "The Inkspire" design-system draft, preserved byte-for-byte as standard §35 requires.
- **Produced:** 2026-10-12 UTC during the Director's design brainstorm. Its last change is recorded inside as 2026-10-12T07:42:00Z.
- **sha256:** `add42af27f65ab577cd0e33941699cd3afc05a3e1ceca5c91e4962b94dc8647e`.
- **Contents (14 entries):** a README, eight sections (identity; world and rooms; cards and table; motion and sound; accessibility and language; anti-slop standard; official assets; platform), a cover preview and `design-system.json`.

The adopted [UX/UI design system standard](../../vision/UX_UI_DESIGN_SYSTEM.md) supersedes it. That standard's §3 records how each of this draft's statements was resolved; for example, "Phone equals desktop" became desktop and tablet first, with complete phone journeys staged. The draft's rough technical statements must not override the standard. Recorded by CHG-20261020-004.
