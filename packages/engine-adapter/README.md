# Server engine adapter

`@lorcana/engine-adapter` is server-only. RULE-03 exports `createQualificationMatch({players,startTimestamp})`, `verifyCompletedReplay(archive,trustedDigest)`, ENGINE_QUALIFICATION, assessEngineAdmission and owned declarations. New matches generate their own private32-byte Node crypto seed; caller seed fields reject. The frozen handle exposes status/submit/exportReplay/dispose. Live status contains qualification mode, revision, ended, winner, choosingFirstPlayer, rewardEligible:false and a seed commitment, with no seed/state/RNG/viewer map. Export rejects until completion and after disposal. Completed archives are internal private objects, not public DTOs.

Application services must import this boundary; direct vendor/@tcg/raw-engine/Lab imports and unchecked module-loader aliases reject. Only this adapter and browser Lab own the compiled pure-kernel edge. Current HTTP diagnostics do not import it or expose match ingress. Node24 qualification exercises compiled opening, mulligan, concession, deterministic reconstruction and disposal without Bun/source loading. The indexed HMAC stream has separate domains for identifiers, floats and unbiased bounded integers; provider/entropy failure fails closed. RULE-04 official behavior and PLAY-02 projections, with other AUTH/PLAY/economic prerequisites, still block rewarded/private play. Ordinary Lab and Collection Play remain blocked.

Public package shapes, bounds/errors and lifecycle are in [the runbook](../../docs/runbooks/engine.md); [RULE-03 validation](../../docs/validation/rule-03.md) records execution and [ADR0010](../../docs/adr/0010-secure-randomness-replay.md) the design. Replay identity hashes actual compiled adapter/kernel bytes and kernel provenance; an archive verifies only with the matching identity and a separately trusted digest. Director D10 restricts seed/full private replay disclosure to participants and authorized auditors; authentication, delivery and access enforcement at transport are later AUTH/REPLAY work. Synthetic twelve-card decks are not legal constructed decks. Captured timestamps/command IDs do not implement durable receipts, idempotency or a complete clock policy. Journal limits are2048 validated attempts/2MiB; speculative overflow restores the prior state. Disposal clears owned seed buffers and drops kernel/journal references; it does not promise full heap erasure. No database, auth or listener is created here.
