# Trust-free synthetic engine harness

`@lorcana/engine-lab` is browser-scope and owns the permitted browser compiled vendor-kernel import; the server-only engine-adapter owns a separate server edge. It exports strict project interfaces and a standalone `./worker` bundle. The web app does not load this worker; lazy integration, Workbox and device/loading qualification remain later work.

`createLabMatch(unknown)` accepts only closed synthetic qualification/advanced-sandbox options, bounded seed and two distinct players. It privately owns the kernel and exposes status/submit/dispose; rewardEligible is always false. Actor/revision/terminal rejection, bounded JSON copying and idempotent disposal are enforced. Malformed data/disposed access throws. The worker owns one match; closed init/status/submit/dispose messages return bounded summaries/results. Active reinitialization rejects; disposal permits a fresh init. Errors become fixed LAB_REQUEST_REJECTED without input/state/error reflection.

`assessEngineAdmission(unknown)` separates calendar phases from qualification. Official rules/sets, ordinary Lab, Collection Play, rewards and hidden-state requests are rejected. Only synthetic-fixture/TST qualification or manipulated Sandbox can pass. CR2.3 effective October16 and Hyperia14 prerelease October16/general release October23 cannot change admission automatically.

RULE-03 moves seedrandom3.0.5 into this owning browser workspace. Its explicit indexed provider is noncompetitive, including float-derived bounded integers; it does not claim server cryptographic security. Lab captures synthetic clock0 and chooser p1, preserving its diagnostic flow. Lab/worker have no seed export, replay export, snapshot/restore or random-stream RPC. Raw worker requests for those methods reject with LAB_REQUEST_REJECTED.

See [the runbook](../../docs/runbooks/engine.md) for fields/limits, [ADR0010](../../docs/adr/0010-secure-randomness-replay.md) for the server/Lab split and [RULE-03 validation](../../docs/validation/rule-03.md) for actual checks. No official catalog, secure server RNG/replay, private live game or economy is implemented in Lab. Server-private reconstruction belongs exclusively to engine-adapter.
